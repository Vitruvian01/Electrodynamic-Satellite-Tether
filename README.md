# Electrodynamic-Satellite-Tether
This is the code I developed for my undergraduate honors thesis. It utilizes my own code, a number of space environment models, and the Python API of NASA's GMAT software to simulate the physics and orbital evolution of an electrodynamic satellite tether. The forces code simulates the electrodynamic and aerodynamic forces on a tether in depth, while the lifetimes code simulates its long-term orbital evolution with GMAT. Both of these files start with instructions for use.
